# CSV data-cleaning checklist

A useful CSV cleanup is more than deleting duplicate rows. Before importing a file into a CRM, ecommerce platform or database, check the structure and preserve a traceable source copy.

## Core checks

- consistent header names
- expected column count
- exact duplicate rows
- duplicate business keys such as SKU, email or ID
- missing required fields
- leading/trailing whitespace
- inconsistent date or numeric formats
- malformed email/URL fields where basic validation is appropriate
- encoding/delimiter problems
- rows that are shorter or longer than expected
- suspicious zero/negative values where the field should normally be positive
