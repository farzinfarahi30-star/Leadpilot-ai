# NOVA — Global Public Web3 Bounty Directory (10 October 2026)

This is a **real inventory of ALL currently visible program entries found on two major Web3 bug-bounty platforms**, not merely a curated top 30. Data collected using the official Immunefi public JSON endpoint and all 33 paginated HackenProof directory pages, on 2026-10-10. **It is not a claim of every worldwide bug bounty**: independent, private, and other-platform programmes are outside this exact two-provider dataset.

## Verified counts

- Immunefi: **232 API records; 169 publicly live, 1 invite-only active, 62 closed**.
- HackenProof: **324 directory entries; 151 live, 35 paused, 138 finished**.
- **556 total listed entries**, including historical / paused records.
- **320 live public programme entries** across these two platforms; programmes may refer to the same project (not 320 independent sponsors).
- **71 live Immunefi programmes explicitly flag no KYC**. HackenProof KYC is unverified and each programme should be checked individually.

## Other platforms (additional independently maintained directories)

- [Sherlock audit contests](https://audits.sherlock.xyz/contests): competition windows and participant conditions vary.
- [Cantina competitions](https://cantina.xyz/competitions): contest lists and potential private or KYC gates.
- [Cyfrin CodeHawks competitions](https://codehawks.cyfrin.io/): paid audit contests. **First Flights often award experience rather than monetary prizes**.
- [Hats Finance](https://app.hats.finance/): decentralized bounty vaults; confirm active funding and eligibility.
- [Code4rena](https://code4rena.com/audits): its own site announces it is **winding down**; do not count ended contests as current earning opportunities.
- [SmartContractsHacking aggregator](https://smartcontractshacking.com/tools/web3-auditing-competitions-and-bug-bounties/): combines programme directories, not additional independent bounties; avoid counting duplicates.

Each report must follow the exact programme's legally authorised scope and disclosure process. No access to user funds, no mainnet exploitation, no attacks on out-of-scope systems and no claims of earnings without platform-confirmed awards/payouts.
