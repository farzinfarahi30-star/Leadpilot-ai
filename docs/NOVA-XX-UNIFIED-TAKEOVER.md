# Nova XX Unified Takeover

XX is the single takeover control for the user-owned systems represented in this repository.

The registry currently contains:
- AI Business Factory
- NOVA Economic/Crypto Layer

Each target has its own manifest, validator, runner and proof. The unified handoff verifies that every registered target is structurally complete and hands both targets to Nova under the same control rule.

The system never stores private keys, wallet seeds, OAuth refresh tokens or provider secrets in the takeover artifacts. Production financial actions remain subject to their actual external authorization and security requirements.

The unified proof is generated by `.github/workflows/nova-xx-unified-takeover.yml`.
