# Nova Website Technical Audit

A fixed-price technical audit for one public webpage.

**Price:** £9 one-time  
**Checkout:** https://buy.stripe.com/4gM9AT3jm1a656Hc0p9Zn0V

## What you receive

- HTTP status and selected response headers
- page title and meta description review
- canonical, robots and language checks
- H1/H2, image and link counts
- images missing alt text
- mobile viewport signal
- Open Graph and Twitter metadata checks
- JSON-LD structured-data detection
- selected security-header checks
- a transparent heuristic score
- a prioritized issue list

Enter the public webpage URL directly at Stripe checkout. The report is delivered to the email used at checkout.

## Scope

One public webpage URL per purchase. This is a technical website review, not a guarantee of traffic, rankings, conversions or revenue. The service does not request passwords and does not intentionally crawl an entire site.

## Infrastructure

Nova maintains the audit engine as portable source code so the service is not dependent on temporary tunnel URLs or time-limited browser automation. The deployment target can be moved between self-hosted and free-tier edge runtimes without changing the customer offer.
