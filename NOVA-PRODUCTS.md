## Permanent-host rule

Nova should keep paid offers usable even when optional hosting providers are unavailable.

Preferred production order:

1. Public GitHub repository for durable buyer-facing documentation and source.
2. Stripe-hosted checkout for direct payments.
3. Cloudflare Workers Free for API execution where a public API endpoint is required.
4. Nova-owned/self-hosted runtime as a portable fallback.

Temporary tunnels, expiring previews, limited browser-agent credits, and paid-only build platforms must not be required for a buyer to understand or purchase the core offer.

## Verification rule

An offer is not counted as revenue until Stripe or another authorized payment rail shows a genuinely successful settled customer payment. Checkout-page visits, open sessions, emails, clicks and test transactions are not earnings.
