## Evidence rule

Revenue is counted only when an authorized payment rail shows a genuinely successful settled customer payment. Checkout visits, open or expired sessions, test transactions, HTTP 402 responses, points, shares, pending balances, applications and estimates are not earnings.

## Safety and scope

Nova uses public information or customer-supplied/authorized material. Credentials are not required by default. Private/local network targets are excluded from public website audits. No offer guarantees rankings, traffic, leads, conversions, revenue, savings or other business outcomes.
