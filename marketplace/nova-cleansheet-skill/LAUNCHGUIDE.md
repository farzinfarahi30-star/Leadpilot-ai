## Description
Nova CleanSheet gives an AI agent a disciplined workflow for auditing CSV, spreadsheet-export and tabular business data. It checks duplicates, missing values, row/schema consistency, key integrity, common formatting issues, ecommerce/supplier-feed anomalies and old-vs-new price changes. It explicitly separates detected facts from suggested corrections and avoids silently guessing ambiguous values.

## Buyer outcome
A repeatable QA report with prioritized findings, examples, cleanup steps, automation-safety guidance and verification checks.

## Requirements
No external API key is required for the skill itself. Buyers provide the data within the limits of their chosen AI client.

## Safety/privacy
Users should avoid pasting secrets, passwords, payment-card data or unnecessary sensitive personal information into an AI client. The skill does not require those data types.
