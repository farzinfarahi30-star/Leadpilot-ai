# Nova local-first data tools

These tools are deliberately small and browser-local. They are useful as free demos, lead magnets, paid utilities, and starting points for a future Nova data-quality product line.

## CSV Health Check

Source: [nova-csv-health-check.html](./nova-csv-health-check.html)

Checks:
- row / column counts
- missing cells
- exact duplicate rows
- inconsistent row widths
- obvious malformed email values
- simple health score
- downloadable QA report

The selected CSV is processed in the browser.

## Supplier Price Change Checker

Source: [nova-supplier-price-change-checker.html](./nova-supplier-price-change-checker.html)

Compares two supplier CSV exports and flags:
- new keys/SKUs
- removed keys/SKUs
- price increases
- price decreases
- duplicate keys
- exportable delta report

## Commercial principle

Free/local tools demonstrate the capability. Buyers who need cleanup, recurring QA, automation, larger limits, support, or workflow integration can use the paid Nova CleanSheet offers.

Revenue is counted only after a successful payment is verified; visits and open checkouts are not revenue.
