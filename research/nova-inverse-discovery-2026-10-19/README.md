# NOVA Inverse Discovery — modular obstruction gate

Reproducible $0, dependency-free research experiment accompanying the 19 October 2026 scientific novelty and income audit.

```sh
python3 test_modular.py
python3 modular_obstruction.py 'x**2+y**2=3'
```

**Verified mathematical scope:** Proves *nonexistence of integer solutions* for polynomial equations when there is a modulus for which every residue tuple fails. It does not determine whether any solution exists when a modulo solution is found, and it cannot prove novel mathematics by itself. `verify_certificate` repeats the exact arithmetic check independently (independent code path, not a formally verified proof assistant). Resource limits: 3 variables maximum, 25k residue tuples/modulus. The tool is a search prototype and has not been security audited.

The primary value is a research workflow: first generate necessary obstructions, then filter known literature, then attempt a formal proof and independent review. Claims of novelty require separate research and human subject-matter review.
