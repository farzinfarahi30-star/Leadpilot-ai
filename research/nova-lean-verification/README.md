# NOVA Lean Proof Gate

This package connects our modular-obstruction research to Lean 4 proof checking.
The proposition verified is a **finite** statement about all 16 pairs of residues
modulo four, not a full quantified theorem over the integers.

Install Lean 4 via elan, then run `lake build` in this directory.
CI uses leanprover/lean-action, a public GitHub repository runner, and a pinned toolchain.

**Novelty statement:** This is established elementary mathematics, not a new theorem.
A Lean proof proves a precisely encoded mathematical proposition, not worldwide novelty.
A historical originality claim requires a comprehensive literature audit and independent
subject-matter scrutiny, and cannot be guaranteed by software alone.
