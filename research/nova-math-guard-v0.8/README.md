# NOVA Math Guard v0.8 — three-valued exact reasoning with real sum-of-squares certificates

**Research status:** working prototype, **not** an original mathematical theorem or a solution to a famous open problem. **Cost:** no paid APIs, standard-library Python 3 for essential proof generation and verification. Optional SymPy is used only for independent differential tests.

## New in v0.8: exact, independently checked **real-only** proof certificates

Version 0.8 adds a generator and independent verifier for a constrained
sum-of-squares (SOS) proof format over **ordered fields containing Q**.
Unlike pure polynomial ideal/radical membership, it can prove real-only
consequences, for example:

```sh
python3 real_sos_prover.py --given 'x**2+y**2=0' --goal 'x=0' -o /tmp/real.json
python3 independent_verifier.py /tmp/real.json
```

The verifier reconstructs `t**2 + sum(weight*square**2) = sum(multiplier*premise)`
using exact rational polynomials and checks every weight is positive. It refuses
complex-field interpretation: `x=i, y=1` refutes this implication over C.

Proof search is **intentionally incomplete**, using up to 4,000 simple bounded
constant-multiplier combinations and an exact rational LDL test on quadratic
residuals. The independent verifier checks the evidence, not the search.

The `real_sos_prover.py` CLI combines field/radical proofs, real-SOS proofs,
and rational countermodels. All failures return UNKNOWN, never a fake theorem.
`RESEARCH_BACKCHAIN.md` sets acceptance criteria for genuine mathematical
novelty. **No novel theorem or famous open problem has been solved.**

## Retained from v0.7: independently verified negative certificates

**A proof search that fails must never declare a theorem false.** Version 0.7
adds a second, independently checkable form of evidence: a rational assignment
at which *all* given polynomial equations hold and the proposed goal equation
fails. The new verifier checks the exact values of every premise and conclusion
without importing the proof-search engine.

```sh
# A valid countermodel of an invalid implication:
python3 conditional_counterexample.py --given 'x*y=1' --goal 'x=y' -o /tmp/counter.json
python3 independent_verifier.py /tmp/counter.json
# Witness: x=2, y=1/2; xy=1 but x != y.

# A valid proof of a different implication:
python3 conditional_counterexample.py --given 'x**2=0' --goal 'x=0' -o /tmp/proof.json
python3 independent_verifier.py /tmp/proof.json
```

Results have **three distinct logical states**: a certificate-verified `PROVED`,
a certificate-verified `DISPROVED`, or `UNKNOWN` if neither witness is found.
A verified rational counterexample refutes universal implication **over Q and
any field containing Q**. Failing to find a rational point in the finite grid
**does not prove anything**: solutions could lie outside the grid, or in a
field extension; real-only properties require separate treatment.

The counterexample schema is `NOVA-MATH-GUARD-CONDITIONAL-COUNTEREXAMPLE-CERT-1`.
The search is explicitly bounded to <=6 variables and <=100,000 tested
assignments, with default rationals 0, ±1, ±2, ±1/2, ±3, ±1/3. The JSON output
records exact premise and goal values, and the verifier checks them afresh.

Run `python3 -m unittest -q test_countermodels` for focused regression tests.
All included examples use established mathematics; the addition is a software
capability, not an original mathematical theorem.

## Retained from v0.6: radical-power certificates

Earlier versions established an implication of equalities only when the goal polynomial `t` was *in the ideal* generated by the hypothesis polynomials `h₁,…,hₘ`. That suffices for proofs, but misses simple true conclusions such as `x**2=0` implying `x=0`.

v0.6 can additionally search for and check a certificate

    t**k = q₁*h₁ + ... + qₘ*hₘ          (2 <= k <= 4)

with rational-coefficient polynomial multipliers. When all hypotheses hold at a point of a **field** containing the rational numbers, the right side vanishes, so `t**k=0`. Fields have no nonzero nilpotents, therefore `t=0`.

**This does not assert that the conclusion holds in arbitrary non-reduced rings.** It also does not decide all logical consequences over the rationals or the real numbers. Every accepted radical certificate is parsed afresh and algebraically checked by `independent_verifier.py`, which imports neither the search implementation nor the main polynomial engine.

## Exact examples

```sh
python3 radical_prover.py --given 'x**2=0' --goal 'x=0' -o /tmp/square.json
python3 independent_verifier.py /tmp/square.json

python3 radical_prover.py --given 'x**3=0' --goal 'x=0' -o /tmp/cube.json
python3 independent_verifier.py /tmp/cube.json

python3 radical_prover.py --given 'x**2=0' --given 'y**3=0' --goal 'x+y=0' -o /tmp/mixed.json
python3 independent_verifier.py /tmp/mixed.json
```

The third example yields this **known classical identity**, checked exactly:

    (x+y)**4 = (x**2)*(x**2+4*x*y+6*y**2) + (y**3)*(4*x+y)

Thus `x**2=0` and `y**3=0` together imply `x+y=0` at every common zero over any field containing Q. The verifier checks the certificate's actual multipliers, not this prose explanation.

The prover **prefers the original v0.5 ideal-membership certificate** when one exists; its new radical search is a bounded fallback for additional consequences.

## Running and testing

```sh
python3 run_all.py
python3 -m unittest -q test_real_sos
python3 research_backchain.py
python3 -m unittest -q test_math_guard test_certificates test_conditional test_groebner test_radical
python3 independent_verifier.py certificates/radical_mixed_nilpotents.json
```

`run_all.py` checks `SHA256SUMS` before running the full suite and independently checks all example certificates. If SymPy is installed, it additionally performs 3,000 baseline polynomial comparisons and 300 radical-witness reconstructions against SymPy; otherwise, these optional tests are skipped with an explicit message. The randomized checks use fixed seeds.

To verify downloaded contents, extract the entire release and run `python3 run_all.py` in the extracted folder. Source or documentation edits require regenerating `SHA256SUMS`; **the manifest detects unintentional changes, not malicious authorship** (there is no digital signature).

## Key project files

- `nova_math_guard.py`: exact rational polynomial arithmetic; no floats.
- `conditional_prover.py` and `groebner_prover.py`: bounded ideal-membership search with lifts back to original hypotheses.
- `radical_prover.py`: v0.6 bounded power-ideal search, outputs `NOVA-MATH-GUARD-RADICAL-CERT-1`.
- `independent_verifier.py`: accepts v0.3 identity, v0.4/v0.5 conditional, v0.6 radical, and v0.7 conditional counterexample certificate formats; checks certificates without trusting the search engine.
- `test_countermodels.py`: exact witness checks, forged-certificate rejection, and deterministic randomized models.
- `conditional_counterexample.py`: three-valued proof-or-refutation with conservative UNKNOWN, using bounded exact rational grid.
- `test_radical.py`: positive cases, deliberate certificate tampering, conservative `UNKNOWN` cases, and 120 deterministic randomized nilpotence cases.
- `differential_radical_sympy_optional.py`: 300 independent randomized algebra expansions against SymPy.
- `CERTIFICATE_THEORY.md`, `THEOREM.md`, `VERIFICATION.md`: semantics, limitations and recorded test commands.
- `certificates/radical_*.json`: portable exact proof witnesses.
- `certificates/conditional_*countermodel.json`: portable exact negative witnesses.
- `COUNTERMODEL_THEORY.md`: new rational countermodel soundness scope and limitations.
- `run_all.py`, `SHA256SUMS`: single-command verification and file-integrity checks.

## Important limits

- **No Lean 4 formal-kernel integration yet.** Lean was not available in this local test environment. Python arithmetic and the independent verifier can still contain bugs.
- The positive proof search is limited by exponent (`<=4`), number of equations (`<=8`), maximum polynomial size/degree, coefficient growth, basis size, and reduction budgets; `UNKNOWN` means *no certificate found under those bounds*, **not** that a statement is false.
- `x**2 + y**2 = 0` implies `x=0` over the real numbers but **not over the complex numbers** (`x=i, y=1`). A proof restricted to the radical ideal of the complex zero set cannot establish that real-only inference; v0.6 correctly declines to claim it.
- Conditional proofs can be vacuously true when assumptions are inconsistent; the system does not certify that the hypothesis system has a solution.
- Do not expose these CLIs directly to untrusted public traffic without an OS-level resource sandbox.
- Every example is **known mathematics**, not a new theorem. Publication of this software is not an announcement of a historic mathematical discovery.
